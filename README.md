# 臨床分子栄養医学研究会 総会 発表者募集 LP

GitHub Pagesで公開できる静的LPです。

## 公開前に変更するところ

`index.html` の下記URLを、実際のGoogleフォームURLに差し替えてください。

```html
https://forms.gle/REPLACE_WITH_YOUR_FORM
```

去年の開催写真を `assets` フォルダに入れて、下記のファイル名にしてください。

```text
assets/soukai-2025-1.jpg
assets/soukai-2025-2.jpg
assets/soukai-2025-3.jpg
```

`soukai-2025-1.jpg` はファーストビューのメイン写真にも使われます。

現在は下記の写真をWeb用に軽量化して配置しています。

```text
soukai-2025-1.jpg ← 250907_1642.jpg
soukai-2025-2.jpg ← 250907_1611.jpg
soukai-2025-3.jpg ← 250907_0132.jpg
```

## GitHub Pagesで公開する手順

1. このフォルダの中身をGitHubリポジトリにアップロードします。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` を `Deploy from a branch` にします。
4. `Branch` を `main`、フォルダを `/root` にして保存します。

数分後に公開URLが表示されます。
